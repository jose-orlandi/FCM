# Projeto_FCM

Projeto de exemplo em R para criação de gráficos com a biblioteca `ggplot2`.

## Descrição

Este repositório contém um script que gera um gráfico de linha com a variação da temperatura ao longo dos meses. O exemplo usa dados fictícios para ilustrar como construir visualizações em R com aparência simples e profissional.

## Estrutura do projeto

- `teste.R` - script principal em R que gera o gráfico.

## Requisitos

- R instalado
- Pacote `ggplot2`

## Instalação

Se o pacote ainda não estiver instalado, execute:

```r
install.packages("ggplot2")
```

## Como executar

1. Abra o arquivo `teste.R` no RStudio ou em outro ambiente R.
2. Execute o script.
3. O gráfico será gerado no painel de visualização.

## Exemplo de saída

O script produz um gráfico de linha com:

- eixo X: meses do ano
- eixo Y: temperatura em °C
- título: "Temperatura ao longo dos meses"

## Observação

Este projeto é um exemplo didático para demonstração de visualização de dados em R e pode ser usado como base para outros estudos mais avançados.
